# Portfolio — four projects + Book With Me

This repair edition is **self-contained**: all styles, behavior, and original design images are embedded inside each HTML page. No `assets/`, `.css`, or `.js` files need to be uploaded.

## Publish to Angie22-dev/Portfolio
1. Open https://github.com/Angie22-dev/Portfolio
2. Replace these existing files in the repository root: `index.html`, `zeneith.html`, `cloudhire.html`, `datatitan.html`, `marin.html`, `book.html`.
3. Commit the replacements to the `main` branch.
4. Ensure Settings > Pages publishes from `main` / `(root)`; visit https://angie22-dev.github.io/Portfolio/ .
5. Hard refresh (Ctrl+Shift+R).

The four original projects are Zeneith, Cloudhire, Datatitan and Marin. `Book With Me` leads to the booking page with https://cal.com/angie-singleton-ndsv5v/ . The visible Contact navigation and Contact/Schedule footer links have been removed.

If GitHub's web upload declines to replace an existing file, open that file in GitHub, choose Edit (pencil), paste the replacement file contents, and commit, or use GitHub Desktop to replace all six files in one commit.
